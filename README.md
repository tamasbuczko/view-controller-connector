# View–Controller Connector (VCC)

Beágyazható webmodul: **Observer / View / Controller** szerepekkel összeköti a böngészőben futó eszközöket (üzenetek + WebRTC média). Első demó PHP hosttal; későbbi cél a karate verseny oldal.

## Állapot

**Tervezés rögzítve** — kód még nincs.
